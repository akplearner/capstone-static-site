## Exam coverage — 96% of the exam weight is practised

| Domain | Weight | Practised by |
| --- | --- | --- |
| Cloud concepts | 25–30% | Set the standard, the budget and the service model; Draw the request flow and say who manages each hop |
| Azure architecture and services | 35–40% | Create the resource group and VNet; Add the team to the account and give them access; Deploy the tools VM; Publish the website with HTTPS; Put an NSG on the subnet and allow SSH from your IP; Create Cosmos DB and seed the counter; Build the visitor-counter Function; Give the team the right access |
