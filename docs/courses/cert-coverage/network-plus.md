## The ladder

## Exam coverage — 100% of the exam weight is practised

| Domain | Weight | Practised by |
| --- | --- | --- |
| Networking Concepts | 23% | Discover before you design; Plan the addresses and the VLANs |
| Network Implementation | 20% | Build the empty topology; Cut the switches into VLANs; Route between them and out; Hand out addresses and names; Research the equipment; Build it on hardware |
| Network Operations | 19% | Watch it and back it up; Change it properly; Price the bill of materials; Plan the move and hand over |
| Network Security | 14% | Enforce the policy |
| Network Troubleshooting | 24% | Work three faults by layer; Write down what differed |
