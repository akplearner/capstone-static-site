## Exam coverage — 100% of the exam weight is practised

| Domain | Weight | Practised by |
| --- | --- | --- |
| Orchestration | 25% | Compose the multi-container stack; Deploy it to a Swarm; Scale it, and roll a bad update back |
| Image Creation, Management, and Registry | 20% | Build and tag the app image; Push it to a registry |
| Installation and Configuration | 15% | Configure the daemon and logging |
| Networking | 15% | Wire the network and resolve by name; Work a connectivity fault, one change per row |
| Security | 15% | Scan the image and read the findings; Run it least-privileged, secrets out; Hand the stack over |
| Storage and Volumes | 10% | Persist the data in a volume |
