## The ladder

## Exam coverage — 100% of the exam weight is practised

| Domain | Weight | Practised by |
| --- | --- | --- |
| Cloud Concepts | 24% | Set the standard, the budget and the service model; Draw the request flow and say who manages each hop |
| Security and Compliance | 30% | Add the team to the account and give them access; Allow SSH from your IP only; Give the team the right access; Find who changed it in CloudTrail and write the incident record |
| Cloud Technology and Services | 34% | Create the VPC and public subnet; Open the team repository and board; Launch the tools instance; Publish the website with CloudFront; Create the DynamoDB table; Build the counter Lambda and API; Alarm on Lambda errors; Find a failure in CloudWatch Logs |
| Billing, Pricing and Support | 12% | Estimate the cost and choose storage classes; Report the cost, and read Trusted Advisor and the support plans |
